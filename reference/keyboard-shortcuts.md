# Keyboard Shortcuts

The full list is in the editor: toolbar **Edit > Shortcuts…**

<figure><img src="../.gitbook/assets/shortcuts-window.png" alt=""><figcaption></figcaption></figure>

## Common shortcuts

| Action | Shortcut |
|---|---|
| Open Spreadsheet window | **Ctrl/Cmd + Shift + T** |
| Save snapshot | **Ctrl/Cmd + S** |
| Undo | **Ctrl/Cmd + Z** |
| Redo | **Ctrl/Cmd + Shift + Z** |
| Copy / Cut / Paste cells | **Ctrl/Cmd + C / X / V** |
| Move between cells | Arrow keys |
